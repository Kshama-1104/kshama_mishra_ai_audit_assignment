## File Descriptions

- **NOTEBOOK.md** – Engineering notebook documenting investigation, experiments, and decisions.
- **AI_USAGE.md** – Summary of AI assistance used while completing the assignment.
- **partA/tokenizer_audit.md** – Final tokenizer audit report with findings and recommendations.
- **partA/analyze_tokenizers.py** – Script used to reproduce tokenizer analysis and metrics.
- **partA/prepare_flores_corpus.py** – Prepares the FLORES-200 multilingual evaluation corpus.
- **partA/corpus_flores200/** – Evaluation datasets used for tokenizer analysis.
- **partB/capacity_reconciliation.md** – Analysis reconciling theoretical and measured serving capacity.
- **partC/memo.md** – Engineering recommendation memo for model deployment.
- **starter_kit/** – Original assignment materials provided for the audit, including baseline code, benchmark data, and sample corpus.
